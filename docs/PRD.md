# 모임 이벤트 관리 MVP PRD

## 🎯 핵심 정보

**목적**: 모임 주최자가 참석자 집계와 정산을 카카오톡 단톡방에서 수작업으로 처리하는 문제를 해결한다.
**사용자**: 수영·헬스·친구 모임을 정기적으로 주최하며 참석 인원과 회비를 직접 관리하는 사람.

## 🚶 사용자 여정

```
1. 랜딩 페이지
   ↓ [로그인] 클릭

2. 로그인 페이지
   ↓ 카카오 또는 구글 인증

3. 대시보드
   ↓ [새 이벤트] 클릭

4. 이벤트 생성 페이지
   ↓ 제목/일시/장소/정원 입력 후 [만들기]
   ↓ 카톡 공유 텍스트 복사 → 단톡방에 붙여넣기

5. 이벤트 관리 페이지
   ↓ 참석 현황 확인 → 필요 시 공지 추가
   ↓ 모임 종료 후 정산 생성 → 입금 체크

──────────────── 참여자 흐름 ────────────────

1. 초대 페이지 (링크로 진입)
   ↓ 이벤트 정보 확인 (로그인 없이 열람 가능)
   ↓ [응답하기] 클릭

   [비로그인] → 로그인 페이지 → 인증 완료 → 초대 페이지로 자동 복귀
   [로그인됨] → 바로 응답 폼 표시
   ↓

2. 초대 페이지 (응답 폼)
   ↓ 참석/불참/미정 + 동반 인원 + 한마디 입력

3. [완료] → 참석자 명단 확인 / 응답 수정 / 본인 정산 몫 확인
```

## ⚡ 기능 명세

### 1. MVP 핵심 기능

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |
|----|--------|------|-------------|------------|
| **[F001]** | 이벤트 생성 | 제목·일시·장소·안내·정원·응답 마감을 입력해 모임을 만들고 고유 초대 링크를 발급 | 모든 흐름의 시작점 | 이벤트 생성 페이지 |
| **[F002]** | 초대 링크 공유 | 발급된 링크를 복사해 단톡방에 전달 | 참여자를 모으는 유일한 경로 | 이벤트 생성 페이지, 이벤트 관리 페이지 |
| **[F003]** | 참석 응답(RSVP) | 참석/불참/미정 선택, 동반 인원, 한마디 입력. 재방문 시 기존 응답 수정 | 집계 데이터를 만드는 핵심 행위 | 초대 페이지 |
| **[F004]** | 참석 현황 집계 | 상태별 인원 자동 집계, 동반 인원 합산, 정원 대비 현황 표시 | "저요"를 세지 않게 하는 핵심 가치 | 이벤트 관리 페이지, 초대 페이지 |
| **[F005]** | 공지 등록·열람 | 모임 생성 후 추가 공지를 누적 등록하고 초대 페이지 상단에 노출 | 장소·시간 변경 전달이 실사용에서 필수 | 이벤트 관리 페이지, 초대 페이지 |
| **[F006]** | 카톡 공유 텍스트 생성 | 현재 참석 현황과 링크가 포함된 문구를 자동 생성해 복사. 이벤트 생성·공지 추가·정산 요청 3종 | 참여자에게 도달하는 유일한 수단 | 이벤트 생성 페이지, 이벤트 관리 페이지 |
| **[F007]** | 정산 생성·N빵 계산 | 총액 입력 시 참석자 수로 자동 분배(불참자 제외), 1원 단위 나머지는 주최자 귀속. 계좌 정보 등록·복사 | 카톡이 대체할 수 없는 차별 기능 | 이벤트 관리 페이지 |
| **[F008]** | 입금 확인 체크 | 참석자별 입금 여부를 체크하고 미입금자 수·금액을 실시간 표시 | 정산을 끝까지 완결시키는 기능 | 이벤트 관리 페이지 |
| **[F009]** | 본인 정산 내역 확인 | 참여자가 본인이 낼 금액과 입금 처리 여부를 확인 | 주최자에게 되묻는 일을 없앰 | 초대 페이지 |

| ID | 기능명 | 설명 | MVP 필수 이유 | 관련 페이지 |

| **[F014]** | 명단 공개 설정 | 참여자에게 다른 참석자 이름을 보일지 주최자가 선택 | 모임 성격에 따른 최소 프라이버시 제어 | 이벤트 관리 페이지 |
| **[F015]** | 개인정보 처리 안내 | 수집 항목·이용 목적·보유 기간을 고지 | 이름·참석 이력 수집에 따른 최소 고지 | 개인정보 처리방침 페이지 |

### 3. MVP 이후 기능 (제외)

- 카풀 매칭 및 좌석·유류비 배분
- 카카오 알림톡·이메일 발송, 웹 푸시 알림
- 결제·송금 앱 연동 (계좌 복사로 대체)
- 정기모임 그룹 계층 및 고정 멤버 관리 (이벤트 복제로 대체)
- 댓글·채팅, 항목별 차등 정산, 프로필 상세 관리

## 🛠️ 기술 스택

> 이 프로젝트의 **실제 설치 버전** 기준입니다.

### 🎨 프론트엔드 프레임워크

- **Next.js 16** (App Router, Cache Components 활성) - React 풀스택 프레임워크
- **React 19** - UI 라이브러리
- **TypeScript 5** - 타입 안전성 보장

### 🎨 스타일링 & UI

- **TailwindCSS v4** (설정파일 없는 새로운 엔진) - 유틸리티 CSS 프레임워크. 테마는 `app/globals.css`의 `@theme` 블록에서 정의하며 `tailwind.config.ts`는 사용하지 않음
- **@tailwindcss/postcss** - v4 전용 PostCSS 플러그인 (autoprefixer 불필요)
- **shadcn/ui** (new-york 스타일, neutral 베이스) - React 컴포넌트 라이브러리
- **Lucide React** - 아이콘 라이브러리
- **next-themes** - 다크 모드 (`@custom-variant dark`로 클래스 기반 전환)

### 📝 폼 & 검증

- **React Server Actions** - 폼 제출 처리
- **Zod** - 스키마 검증 (신규 도입 필요)

### 🗄️ 백엔드 & 데이터베이스

- **PostgreSQL** - 관계형 데이터베이스 (Supabase 포함)
